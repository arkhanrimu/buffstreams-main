Troubleshooting

If you encounter any issues during the download or installation process, try the following solutions:

  • "Install Blocked" Error: You haven't enabled Unknown Sources. Go to your device settings and enable the option as described above. If you're on Android 8.0+, make sure you've enabled it specifically for the browser or file manager you're using.
  • "App Not Installed" Error: This usually means you already have an older version installed. Uninstall the existing Buffstreams app first, then try installing the new APK again. Alternatively, ensure you have enough storage space on your device.
  • APK File Won't Download: Check your internet connection and try again. Make sure you have sufficient storage space. If the download keeps failing, try using a different browser or clearing your browser's cache.
  • App Crashes on Launch: Ensure your device meets the minimum requirements (Android 5.0 or higher). Try clearing the app's cache and data from your device settings, or uninstall and reinstall the app.
  • App Not Working on Android TV: Make sure you've installed the correct version designed for Android TV. Some features may require a mouse or remote for navigation. Consider using a Bluetooth mouse for easier navigation on TV devices.
  • Slow Performance: Close other background apps to free up memory. Ensure you have a stable and fast internet connection. Try clearing the app's cache if performance issues persist.
